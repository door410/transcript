## 1. 這個工具依賴哪些外部東西

「依賴」就是「不是你寫的、但你的工具少了它就不能動」的東西。
**長期來看，這些東西比你的程式碼更容易出問題。**

| 依賴 | 用途 | 哪台需要 | 更新頻率需求 | 壞掉時的症狀 |
|---|---|---|---|---|
| **Python** | 執行 ytscript.py | 三台 | **不要隨便升級** | 全部不能動 |
| **youtube-transcript-api** | 引擎 1：最快抓字幕 | 三台 | 壞了才更新 | 引擎 1 失敗（會自動退到引擎 2） |
| **yt-dlp** | 引擎 2、下載音訊、影片資訊 | 三台 | **要常更新**（YouTube 一直改） | 抓不到字幕、Sign in to confirm |
| **opencc-python-reimplemented** | 簡轉繁 | 三台 | 幾乎不用 | 輸出變簡體 |
| **faster-whisper** | 電腦 AI 聽寫 | 桌機、筆電 | **不要隨便升級** | 沒字幕的影片失敗 |
| **ctranslate2** | faster-whisper 的核心 | 桌機、筆電 | **不要隨便升級** | 同上，或 GPU 失效 |
| **nvidia-cublas-cu12、nvidia-cudnn-cu12** | GPU 加速 | 只有桌機 | **不要隨便升級** | GPU 失效、自動改 CPU（變慢） |
| **NVIDIA 驅動** | GPU | 只有桌機 | Windows 可能自動更新 | 同上 |
| **Whisper 模型** | AI 聽寫的大腦 | 三台 | 不需要更新 | 下載失敗 |
| **whisper.cpp** | 手機 AI 聽寫 | 只有手機 | 不需要更新 | 找不到執行檔 |
| **ffmpeg** | 手機音訊轉檔 | 只有手機 | 跟著 Termux 升級 | 需要 ffmpeg |
| **Termux** | 手機的 Linux 環境 | 只有手機 | 從 F-Droid 更新 | 各種奇怪錯誤 |
| **Google Fonts** | 畫面字型 | 三台 | — | 離線時字型不同（功能不受影響） |

### 版本鎖定：`requirements/` 資料夾

2026-09-24 以前，三個安裝管道全部是 `pip install --upgrade`，永遠裝最新版——今天重新安裝和三個月前裝到的版本可能完全不同，
上游一發布不相容的新版，重灌就會壞，而且不知道是哪個套件造成的。

現在三個安裝管道（`安裝.bat`、首次啟動的 `ensure_deps()`、`android/install.sh`）**都從同一個資料夾讀版本**：

| 檔案 | 內容 | 哪台 | 鎖定方式 |
|---|---|---|---|
| `requirements/core.txt` | yt-dlp、youtube-transcript-api、opencc | 三台 | yt-dlp **只設下限**（必須追著 YouTube 更新）；youtube-transcript-api 限制在 1.x（`<2`，避免 API 大改）；opencc 鎖定 |
| `requirements/whisper.txt` | faster-whisper、ctranslate2、av、onnxruntime、tokenizers、huggingface_hub | 桌機、筆電 | **全部鎖定**（互相綁定，也要和 CUDA 配合） |
| `requirements/gpu.txt` | nvidia-cublas-cu12、nvidia-cudnn-cu12 | 只有 NVIDIA 顯卡 | **全部鎖定** |

實測環境：Windows 10、Anaconda Python 3.13.9、GTX 1050 Ti，`selfcheck --whisper` 全部通過（2026-09-24）。

**鎖定版本裝不起來時**（例如筆電的 Python 版本不同，沒有對應的安裝檔）：`安裝.bat` 會顯示 `[WARN]`
並改裝最新版，讓工具至少能用。這時請跑 `python tools/selfcheck.py --whisper`：通過就沒問題，
「套件是實測過的版本」那一項會提醒你版本不同。

另外，whisper.cpp（手機）也固定在 `v1.9.4`（`android/install.sh` 的 `WHISPER_TAG`）。

### ⚠️ `requirements/*.txt` 必須純 ASCII

pip 在 Big5 的 Windows 上可能用 Big5 讀這些檔案，只要一個中文字（包含註解）就可能讓安裝失敗。
selfcheck 的「.bat／.vbs 維持純 ASCII」這一項會一併檢查它們。

## 2. 確認每台裝的是實測版本

不用另外記錄，跑自我檢查就好：

```bash
python tools/selfcheck.py
```

看「套件是實測過的版本」這一項：

| 顯示 | 意思 |
|---|---|
| `core.txt、whisper.txt、gpu.txt 都符合` | 完全是實測過的組合 |
| `注意，與實測版本不同：…（能用就不必處理）` | whisper／gpu 的版本不同（通常是鎖定版本裝不起來、自動改裝了最新版）。工具能用就不必處理 |
| `[失敗] …` | core.txt 的條件不符合（例如 yt-dlp 太舊）。照提示執行 `python -m pip install --upgrade -r requirements/core.txt` |

筆電、手機第一次跑到全部通過時，記在第 09 章的測試紀錄表。

## 3. 如何更新套件

### 原則

| 套件 | 策略 |
|---|---|
| **yt-dlp、youtube-transcript-api** | **抓不到字幕時就更新。** 這兩個是「追著 YouTube 跑」的套件，舊版會越來越不能用 |
| **faster-whisper、ctranslate2、nvidia-*、av、onnxruntime** | **能用就不要動。** 這組互相綁定，升級其中一個可能讓其他的不相容，而 GPU 相關問題是最難修的 |
| **Python 本身** | **不要主動升級。** 新版 Python 推出後，ctranslate2 等套件常常要過一陣子才支援 |

### 更新 yt-dlp（最常做的）

```bash
python -m pip install --upgrade -r requirements/core.txt
python tools/selfcheck.py --online
```

這會把 yt-dlp 更新到最新、youtube-transcript-api 更新到 1.x 的最新，opencc 不動。
不需要修改任何檔案（core.txt 裡的 yt-dlp 本來就只設下限）。

手機：

```bash
cd ~/transcript && pip install --upgrade -r requirements/core.txt
```

### 更新 AI 聽寫或 CUDA 套件（真的有需要時）

```bash
# 1. 開分支
git switch -c update/whisper

# 2. 修改 requirements/whisper.txt（或 gpu.txt）裡的版本號，例如 faster-whisper==1.3.0

# 3. 安裝
python -m pip install -r requirements/whisper.txt

# 4. 測試（一定要到第 3 級）
python tools/selfcheck.py --whisper
```

- 通過（並看到「使用顯示卡加速」）→ `git commit` → 併回 main → push。筆電 pull 後重跑一次 `安裝.bat`
- 失敗 → 把版本號改回來、重新安裝，放棄這條分支：

```bash
git switch main
python -m pip install -r requirements/whisper.txt
git branch -D update/whisper
```

### 整組退回實測版本（更新後壞掉時）

```bash
python -m pip install -r requirements/whisper.txt -r requirements/gpu.txt
python -m pip install --upgrade -r requirements/core.txt
python tools/selfcheck.py --whisper
```

（沒有 NVIDIA 顯卡的筆電，第一行拿掉 `-r requirements/gpu.txt`。）

### 手機的系統套件

Termux 的系統套件（python、ffmpeg 等）用 `pkg upgrade` 更新，或直接重跑 `bash android/install.sh`（它會做完整升級並修復常見問題）。

## 4. 如何更新模型

### 模型需要更新嗎？

**基本上不需要。** Whisper 模型是固定的檔案，不會「過期」。下載一次就永久可用。

### 什麼時候會想動模型

| 情況 | 做法 |
|---|---|
| 模型檔壞了（下載到一半中斷） | 刪掉讓它重新下載（下面） |
| 想要更準 | 改 `default_model_size()` 回傳 `"medium"`（1.5 GB，很慢）——請 AI 協助並用 selfcheck 驗證 |
| 想要更快 | 在畫面選「快速」（tiny） |
| 硬碟空間不夠 | 刪掉不用的模型資料夾 |

### 模型存在哪裡、怎麼強制重新下載

**電腦：**

```
C:\Users\你的帳號\.cache\huggingface\hub\
    models--Systran--faster-whisper-tiny\     約 75 MB
    models--Systran--faster-whisper-small\    約 466 MB
```

整個資料夾刪掉，下次 AI 聽寫時會自動重新下載。

**手機：**

```bash
ls -la ~/.cache/whisper-cpp/
rm ~/.cache/whisper-cpp/ggml-tiny-q5_1.bin
```

下次會自動重新下載（31 MB）。

### 模型來源失效怎麼辦（長期風險）

模型是從 Hugging Face 下載的：
- 電腦：`Systran/faster-whisper-*`（由 faster-whisper 套件自動處理）
- 手機：`ytscript.py` 的 `GGML_URL`（`https://huggingface.co/ggerganov/whisper.cpp/...`）

如果有一天這些網址失效：
1. **已經下載過的機器不受影響**（模型在本機）
2. **建議現在就備份模型檔**：把上面的模型資料夾複製一份到隨身碟。這是「就算網路上的東西都消失，工具還能用」的保險
3. 真的失效時，請 AI 協助找新的下載來源，修改 `GGML_URL`

## 5. 如何更新 whisper.cpp（手機）

`android/install.sh` 只在**第一次**時從 GitHub 下載並編譯 whisper.cpp，之後偵測到已經編譯好就跳過。

**不需要更新就不要更新。** 如果真的要重新編譯（例如 Termux 大升級後 whisper-cli 不能執行）：

```bash
rm -rf ~/whisper.cpp
cd ~/transcript && bash android/install.sh
```

⚠️ **風險：** install.sh 每次都抓 whisper.cpp **最新版**。如果上游改了命令列參數，`engine_whispercpp()` 呼叫 whisper-cli 的方式（`-m -f -l -oj -of -np -nt`）可能失效。
重新編譯後一定要測一部**沒有字幕**的影片。失效時，請 AI 對照 whisper-cli 的 `--help` 輸出修改 `engine_whispercpp()`。

## 6. 災難復原流程

### 預防：現在就做的三件事

1. **確認有穩定版 tag**（第 05 章 §9）：目前有 `v2026.09.24`；之後三台都測過再打新的
2. **三台跑 selfcheck，確認「套件是實測過的版本」通過**（本章 §2）
3. **每幾個月做一次離線備份**：

```bash
cd C:\Users\User\projects\yt-transcript
git bundle create D:\備份\transcript-2026-09-24.bundle --all
```

`.bundle` 是**單一檔案**，裡面有完整的 Git 歷史。可以放隨身碟或 Google Drive（單一檔案放雲端沒問題；要避免的是把「整個 repository 資料夾」放在雲端同步資料夾裡）。
從 bundle 還原：`git clone D:\備份\transcript-2026-09-24.bundle transcript`

### 災難 1：桌機壞了／換新電腦

```
1. 安裝 Python（版本盡量和 requirements/whisper.txt 註解寫的實測版本一樣；勾選 Add Python to PATH）
2. 安裝 Git，設定 user.name 與 user.email（第 05 章 §2）
3. git clone https://github.com/door410/transcript.git C:\Users\你\projects\yt-transcript
4. cd 進去，雙擊 安裝.bat
5.（安裝.bat 已經照 requirements/ 裝好實測版本，不用另外做）
6. python tools/selfcheck.py --whisper
7. 如果最新版有問題：git switch --detach 最近的穩定tag
```

### 災難 2：手機重置／換手機

```
1. 從 F-Droid 安裝 Termux 與 Termux:Widget（不要用 Google Play 版）
2. pkg install -y git
3. git clone https://github.com/door410/transcript.git
4. bash transcript/android/install.sh           （約 10～30 分鐘，含編譯 whisper.cpp）
5. python transcript/tools/selfcheck.py
6. 設定 → 應用程式 → Termux → 電池 → 不最佳化
7. 長按桌面 → 小工具 → Termux → 選 YouTube-Transcript
```

### 災難 3：GitHub 上的 repository 不見了（被刪、帳號出問題）

**不用慌：每一台 clone 過的機器，都有完整的歷史。**

```
1. 在 GitHub 建一個新的空 repository（不要勾選加 README）
2. 在桌機：
   git remote set-url origin https://github.com/你的帳號/新名稱.git
   git push -u origin main
   git push origin --tags
3. 筆電與手機：
   git remote set-url origin https://github.com/你的帳號/新名稱.git
4. 修改 android/install.sh 開頭註解、安裝指南.md、README.md 裡的網址
   （以及 ytscript.py 裡 engine_whispercpp 錯誤訊息中的說明）
```

如果連本機都沒有了 → 用 `.bundle` 備份還原。

### 災難 4：程式碼被改得亂七八糟，不知道從哪裡開始壞的

```
1. 別再改了
2. git switch main
3. git log --oneline -20        → 找到最近一個穩定 tag 或你確定能用的 commit
4. git switch --detach 那個編號  → 確認能用
5. 決定：
   · 放棄之後所有修改：git switch main → git revert 編號..HEAD（請 AI 協助確認指令）
   · 或從穩定版開新分支重新做：git switch -c 重新來 那個編號
```

### 災難 5：Claude、GPT 等 AI 都不能用了

- 你的工具**完全不需要 AI 就能運作**（它只是產生給 AI 用的文字）
- 維護：依照本手冊，你還是可以更新套件、退版本、改提示詞與畫面文字
- 你會失去的是「寫新功能」的能力，不會失去工具本身

### 災難 6：YouTube 大改版，所有引擎都抓不到

```
1. 更新 yt-dlp 與 youtube-transcript-api（通常幾天內上游就會修好）
2. 等待。這兩個套件有很大的社群在維護
3. 注意：如果程式判斷「影片其實有字幕，只是現在抓不到」，會**刻意不做** AI 聽寫
   （`transcribe()` 裡的「關鍵防呆」，避免被限流時白白聽寫幾十分鐘）。
   所以 YouTube 擋字幕時，工具不會自動改用聽寫。真的需要時，請 AI 協助暫時停用那段防呆
4. 都不行 → 在 GitHub 上搜尋 yt-dlp 的 issues，看是不是大家都遇到了
```

### 災難 7：faster-whisper 或 CUDA 在電腦上完全裝不起來

- 有字幕的影片完全不受影響
- 沒字幕的影片：電腦版其實**也會試 whisper.cpp**（`transcribe()` 裡電腦的順序是 `[engine_whisper, engine_whispercpp]`）
  所以在 Windows 上安裝 whisper.cpp 的 `whisper-cli.exe` 和 `ffmpeg.exe` 並加入 PATH，就能當備援
  （這是進階做法，請 AI 協助，並用 selfcheck `--whisper` 驗證）

### 不在 repository 裡、但程式會用到的地方

| 位置 | 內容 | 誰產生 | 可以刪嗎 |
|---|---|---|---|
| `~/.cache/yt-transcript/` | 逐字稿快取（每部約 27 KB，最多 100 部） | `cache_save()` | 可以，只是下次要重抓 |
| `~/.cache/huggingface/hub/models--Systran--faster-whisper-*` | 電腦的 AI 模型 | faster-whisper 自動下載 | 可以，下次會重新下載（small 466 MB） |
| `~/.cache/whisper-cpp/` | 手機的 AI 模型 | `install.sh` 或 `ensure_ggml_model()` | 可以，會重新下載 |
| `~/whisper.cpp/` | 手機的聽寫引擎原始碼與執行檔 | `install.sh` 編譯 | 刪了要重跑 install.sh（編譯 5～15 分鐘） |
| `~/ytscript/start.sh` | 手機的啟動器（執行 `~/transcript` 裡的程式） | `install.sh` 產生 | 刪了要重跑 install.sh |
| `~/install-log.txt` | 手機安裝記錄 | `install.sh` | 可以 |
| Python 的 site-packages | 所有 pip 套件 | pip | 不要手動刪 |

（`~` 在 Windows 是 `C:\Users\你的帳號`，在 Termux 是 `/data/data/com.termux/files/home`）

## 4. `ytscript.py` 內部地圖（最重要）

`ytscript.py` 雖然有 1,930 行，但**作者（AI）用分隔線切成了清楚的區塊**。
在檔案裡搜尋 `# ====` 就能看到每一區的開頭。


## 6. 「XX 在哪裡？」速查

| **手機版在哪？** | `IS_TERMUX` 判斷處、`engine_whispercpp()` 一區、`open_url()`、`android/install.sh` |
